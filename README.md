# منصة الطبليات | Pallet Exchange Platform

## 🚀 نظرة عامة

منصة الطبليات هي سوق إلكتروني B2B متكامل لتداول الطبليات (Pallets) في المملكة العربية السعودية. تربط المنصة الموردين بالمشترين من خلال نظام مطابقة ذكي، إدارة مالية متقدمة، ونظام ثقة شامل.

## ✨ الميزات الرئيسية

### للموردين (Suppliers)
- إضافة مخزون الطبليات مع صور ووصف تفصيلي
- إدارة العروض والكميات المتاحة
- تتبع الصفقات من البداية للنهاية
- نظام تقييم وثقة ديناميكي
- لوحة تحكم شاملة للعمليات

### للمشترين (Buyers)
- إنشاء طلبات بمواصفات دقيقة
- مطابقة تلقائية مع المخزون المتاح
- خيارات مرونة (جودة قريبة، مدن قريبة، توصيل جزئي)
- تتبع حالة الصفقات لحظياً
- تقييم الموردين بعد إتمام الصفقات

### للإداريين (Admins)
- لوحة قيادة تنفيذية شاملة
- إدارة كاملة للسوق (المدن، المخزون، الطلبات)
- إدارة الصفقات والنزاعات
- نظام مالي متكامل للعمولات والتسويات
- إدارة المستخدمين والصلاحيات
- إدارة التقييمات والتعليقات
- إعدادات قابلة للتخصيص الكامل

## 🏗️ البنية التقنية

### Frontend
- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State Management**: React Hooks

### Backend
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Custom PIN-based system
- **Storage**: Supabase Storage
- **Realtime**: Supabase Realtime
- **Security**: Row Level Security (RLS)

### الميزات التقنية
- 42 جدول في قاعدة البيانات
- 108+ دالة SQL
- RLS مفعّل على جميع الجداول
- Realtime subscriptions للتحديثات الفورية
- نظام حجز ذكي مع انتهاء تلقائي
- مطابقة تلقائية متقدمة

## 📊 الإحصائيات الحالية

- **المستخدمون**: 40 مستخدم نشط
- **الصفقات**: 16 صفقة (معلقة، مكتملة، ملغاة)
- **المخزون**: 7 دفعات (14,000 طبلية)
- **الطلبات**: 13 طلب
- **التقييمات**: 11 تقييم
- **المدن المدعومة**: 20 مدينة
- **الموظفون الإداريون**: 6 (مع صلاحيات متعددة)

## 🚀 التشغيل

### المتطلبات
- Node.js 18+
- npm أو yarn
- حساب Supabase

### التثبيت

```bash
# استنساخ المشروع
git clone <repository-url>

# تثبيت الحزم
npm install

# إعداد متغيرات البيئة
cp .env.example .env
# أضف VITE_SUPABASE_URL و VITE_SUPABASE_ANON_KEY

# تشغيل المشروع
npm run dev

# البناء للإنتاج
npm run build
```

## 🎯 الأنظمة المتكاملة

### 1. نظام المستخدمين والمصادقة
- تسجيل آمن برقم الجوال و PIN
- جلسات مشفرة مع تجديد تلقائي
- أدوار متعددة (مورد، مشتري)

### 2. نظام المخزون
- إضافة دفعات مع صور (حتى 5 صور)
- حجز تلقائي عند إنشاء الصفقات
- إدارة الكميات المتاحة والمحجوزة

### 3. نظام الطلبات
- مواصفات دقيقة مع خيارات مرونة
- مطابقة ذكية تراعي الجودة والموقع
- إنشاء صفقات تلقائياً

### 4. نظام المطابقة والصفقات
- مطابقة فورية بناءً على المواصفات
- أولوية للموردين ذوي الثقة العالية
- دورة حياة صفقة شاملة (8 حالات)

### 5. النظام المالي
- حساب عمولة تلقائي (افتراضياً 1 ر.س/طبلية)
- تتبع المستحقات والتسويات
- سجل محاسبي كامل

### 6. نظام التقييمات والثقة
- تقييمات بعد إتمام الصفقات
- تقييمات من الزوار في السوق
- مؤشر ثقة ديناميكي (1-5 نجوم)
- تعليقات مع فلترة تلقائية

### 7. نظام الإشعارات
- إشعارات فورية للمستخدمين
- قوالب قابلة للتخصيص
- Realtime updates

### 8. لوحة التحكم الإدارية
- مؤشرات تنفيذية شاملة
- إدارة كاملة للسوق
- صلاحيات متعددة المستويات
- تقارير وتحليلات
